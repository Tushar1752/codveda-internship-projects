# Interactive Form

A professional and interactive registration form developed using HTML, CSS, and JavaScript as part of the Codveda Technologies Front-End Development Internship.

## 🚀 Overview

This project demonstrates client-side form validation and interactive user feedback without requiring a page reload.

The form validates user input in real time and provides clear error messages whenever invalid information is entered.

## ✨ Features

- Full Name validation
- Email validation
- Phone number validation
- Password validation
- Password strength requirements
- Confirm password validation
- Required field validation
- Real-time validation
- Focus and blur interactions
- Dynamic error messages
- Success confirmation
- Form reset after successful submission
- No page reload during validation
- Responsive and professional UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners
- Client-Side Validation

## 📋 Validation Rules

The form checks:

- Required fields
- Valid email format
- Valid phone number
- Minimum password length
- Uppercase character
- Lowercase character
- Number in password
- Matching password confirmation
