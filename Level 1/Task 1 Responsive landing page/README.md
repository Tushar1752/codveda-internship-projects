# Responsive Landing Page

A modern, responsive personal portfolio landing page developed as part of the Codveda Technologies Front-End Development Internship.

## 🚀 Overview

This project is designed to showcase a professional developer portfolio with a clean and responsive interface. It includes sections for introduction, skills, experience, projects, and contact information.

The page is built using semantic HTML, modern CSS layouts, and JavaScript-based interactions to provide a smooth user experience across different screen sizes.

## ✨ Features

- Fully responsive design
- Mobile-first layout
- Semantic HTML5 structure
- Responsive navigation bar
- Mobile hamburger menu
- Hero section
- About section
- Skills and technologies section
- Experience section
- Projects showcase
- Contact section
- Smooth scrolling
- CSS animations and transitions
- Responsive layout using Flexbox and CSS Grid
- Professional modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Responsive Web Design
