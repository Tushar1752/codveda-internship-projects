# CounterX — Basic DOM Manipulation

A minimalist interactive counter application developed using vanilla JavaScript as part of the Codveda Technologies Front-End Development Internship.

## 🚀 Overview

CounterX demonstrates fundamental JavaScript DOM manipulation and event handling through a simple counter interface.

Users can increase, decrease, or reset the displayed counter value dynamically without refreshing the page.

## ✨ Features

- Increment counter
- Decrement counter
- Reset counter
- Dynamic DOM updates
- JavaScript event listeners
- Prevents counter from going below zero
- Minimalist user interface
- Responsive design
- Smooth button interactions

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners
