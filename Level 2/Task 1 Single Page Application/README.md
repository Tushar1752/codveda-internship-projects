# Single Page Application

A modern Single Page Application developed using React as part of the Codveda Technologies Front-End Development Internship.

## 🚀 Overview

This project is a responsive React application with multiple pages and smooth client-side navigation. It demonstrates the use of React Router, Context API, reusable components, and theme switching.

## ✨ Features

- Home, About and Contact pages
- React Router navigation
- Context API for state management
- Light/Dark theme switching
- Responsive design
- Interactive contact form
- Modern and clean UI

## 🛠️ Technologies Used

- React
- JavaScript
- React Router
- Context API
- HTML5
- CSS3
- Vite
