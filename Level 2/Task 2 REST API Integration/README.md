# REST API Integration

A responsive GitHub User Explorer developed using JavaScript and the GitHub REST API as part of the Codveda Technologies Front-End Development Internship.

## 🚀 Overview

This project allows users to search for GitHub usernames and view their profile information and repositories using the GitHub REST API.

## ✨ Features

- GitHub username search
- GitHub REST API integration
- Debounced search
- Loading indicator
- Error handling
- User profile information
- Followers and following details
- Repository information
- Recent repositories
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- GitHub REST API
- DOM Manipulation
